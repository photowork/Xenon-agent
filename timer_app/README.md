# Xenon 独立定时器程序 v1.1 — 多窗口模式

## 架构

每个定时器拥有**独立控制窗口**，互不干扰。

```
timer_app.py 启动
     │
     ├─ 管理器窗口（所有定时器概览）
     │
     └─ 定时器 A 独立窗口 ── 控制 + 日志
     └─ 定时器 B 独立窗口 ── 控制 + 日志
     └─ 定时器 C 独立窗口 ── 控制 + 日志
```

## 快速开始

1. **确保 WebUI 正在运行**
2. 启动定时器程序：
   ```bash
   cd <项目根目录>   # 例如 D:\AI智能体软\Xenon-agent
   python timer_app\timer_app.py
   ```
3. 首次启动自动创建「⏰ 定时任务」会话
4. 点击「➕ 新建定时器」创建任务

## 两种模式

| 模式 | 说明 | 示例 |
|------|------|------|
| 间隔模式 | 每隔 N 秒/分钟/小时触发一次 | 每 30 分钟执行检查 |
| 定时模式 | 每天指定时间触发（可选工作日） | 每天 08:00 发送日报 |

## 多窗口操作

| 操作 | 说明 |
|------|------|
| 新建定时器 | 管理器点击「➕ 新建定时器」→ 自动打开独立窗口 |
| 编辑 | 在独立窗口中点击「✏️ 编辑」 |
| 启用/禁用 | 独立窗口中切换 |
| 删除 | 独立窗口中「🗑️ 删除」或管理器中删除 |
| 关闭窗口 | 禁用定时器，不删除（可在管理器中重新打开） |
| 管理器 | 概览所有定时器状态，双击打开窗口 |

## 配置文件

`config.json` 自动管理，无需手动编辑。
